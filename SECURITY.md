# Security policy

## Supported versions

`baton` is pre-1.0. Security fixes go into the latest release and `main` only.

## Reporting a vulnerability

**Please don't open a public issue for a security problem.**

Report it privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability** ([docs](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). If that isn't available, contact the maintainer [@agarwalvivek29](https://github.com/agarwalvivek29) privately.

Please include:

- what the issue is and its impact
- steps or a minimal reproduction
- the version or commit affected

You'll get an acknowledgement within 7 days. Please allow time for a fix before disclosing publicly; you'll be credited in the release notes unless you'd rather not be.
